# Testovací balíček pro obnovu

Tento dokument je výhradně cvičný. Vytvořte z něj tři samostatné textové soubory ve složce `FOTOKROUZEK-PRACE`.

## soubor `kontakty.txt`

```text
Vedoucí: Jana Modelová
Telefon: 000 000 000
Poznámka: fiktivní výuková data
```

## soubor `plan-vystavy.txt`

```text
1. Výběr fotografií
2. Tisk popisků
3. Instalace panelů
Verze: 1.0
```

## soubor `popisky.txt`

```text
Ranní nádraží — autor Student A
Odraz ve skle — autor Student B
Modré schody — autor Student C
```

## Kontrolní manifest

Před zálohováním doplňte velikost a SHA-256 každého vytvořeného souboru.
