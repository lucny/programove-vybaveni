# Plán segmentace chytré domácnosti

Neuvádějte skutečný název Wi-Fi, heslo, veřejnou IP adresu ani přesný model routeru.

## Modelová zařízení

- pracovní notebook s dokumenty,
- osobní telefon,
- chytrá televize,
- Wi-Fi tiskárna,
- chytrá žárovka,
- návštěvnický telefon,
- domácí úložiště záloh.

## Návrhová tabulka

|---|---|---|---|---|
| | | | | |

## Testovací podmínky

- návštěvnické zařízení dosáhne na internet,
- návštěvnické zařízení nedosáhne na pracovní notebook,
- telefon může ovládat vybrané IoT pouze tehdy, pokud to návrh vyžaduje,
- záloha není dostupná z nedůvěryhodné IoT sítě.
