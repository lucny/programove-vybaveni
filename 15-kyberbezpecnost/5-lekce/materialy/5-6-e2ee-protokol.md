# Protokol ověření bezpečnostního čísla

Nezapisujte celé bezpečnostní číslo ani QR kód. Do protokolu patří jen výsledek porovnání.

| Kontrola | Zařízení A | Zařízení B | Výsledek |
|---|---|---|---|
| kontakt a konverzace byly předem domluveny | | | |
| bezpečnostní číslo otevřeno na obou zařízeních | | | |
| QR porovnán osobně nebo číslo jiným kanálem | | | |
| kontakt označen jako ověřený | | | |
| vysvětlen význam případné změny čísla | | | |

Experiment lze provést jen dobrovolně ve dvojici, která již Signal používá. Jinak se pracuje s učitelskou demonstrací.
