# 2. Interaktivní shrnutí kapitoly

## Licence není vlastnictví autorských práv

U software zpravidla nezískáváme autorská práva, ale [[licenci]] — oprávnění používat dílo za určitých podmínek. Podmínky mohou upravovat počet zařízení, distribuci, modifikaci, aktualizace nebo firemní nasazení.

Pro proprietární software se často používá [[EULA]]. To, že máme instalační soubor, [[ automaticky dovoluje jeho neomezené šíření | (samo o sobě nedává právo jej libovolně distribuovat) | ruší podmínky licence ]].

## Obchodní model není totéž co licence

Proprietární software nemusí být placený. [[freeware]] může být zdarma, ale přesto mít uzavřený kód a omezená práva. Trial je zkušební verze a freemium nabízí základ zdarma a placené rozšíření.

Předplatné znamená periodickou platbu za používání software nebo služby. Při výběru je proto důležité sledovat nejen cenu, ale také export dat, dobu podpory a dlouhodobou [[závislost]] na poskytovateli.

## Open source a copyleft

Open source neznamená „bez autorských práv“. Práva určuje konkrétní [[licence]]. Svobodný software zdůrazňuje možnost program používat, studovat, upravovat a sdílet.

**Vyber správná tvrzení:**

[[X]] MIT a BSD patří mezi permisivní licence.
[[X]] Apache License 2.0 je permisivní.
[[X]] GNU GPL je copyleftová licence.
[[ ]] Každý veřejný repozitář na GitHubu je automaticky open source.
[[ ]] GPL vždy nutí zveřejnit všechny interní úpravy celému světu.

Copyleft může při distribuci odvozeného díla vyžadovat zachování odpovídajících [[svobod]] a zpřístupnění zdrojového kódu podle licence.

## Další modely a praktická odpovědnost

[[source-available]] software zveřejňuje zdrojový kód, ale může omezovat některé způsoby použití a nemusí splňovat definici open source. Creative Commons jsou vhodné hlavně pro texty, fotografie a další obsah; software obvykle používá specializované licence.

Ve škole a firmě je nutné hlídat počet uživatelů, účty a podmínky nasazení. Při vlastním vývoji musí tým sledovat licence a bezpečnost použitých [[závislostí]]. Cena, dostupnost zdrojového kódu a licenční práva jsou tři odlišné věci.
