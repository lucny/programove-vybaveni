# 2. Interaktivní shrnutí kapitoly

## Internet poskytuje více služeb

Web je pouze jednou z internetových služeb. Stejnou síťovou infrastrukturu využívají také elektronická pošta, přenos souborů, vzdálený přístup nebo komunikace v reálném čase. Každá služba používá vhodný [[protokol]], tedy soubor pravidel, podle nichž si programy vyměňují zprávy.

Protokol neoznačuje konkrétní aplikaci. Prohlížeč a webový server jsou programy, zatímco HTTP popisuje [[ vzhled webové stránky | (způsob jejich webové komunikace) | fyzické zapojení kabelů ]].

## Port určuje službu v zařízení

IP adresa pomáhá najít zařízení, ale v jednom zařízení může současně komunikovat mnoho programů. Číslo [[portu]] proto rozlišuje konkrétní síťovou službu nebo proces. Známé porty jsou konvence, nikoli důkaz, že komunikace je bezpečná.

Spojení lze zjednodušeně popsat dvojicí IP adresa a port. Server na určitém portu naslouchá, klient z vlastního dočasného portu navazuje komunikaci.

## Klient–server a peer-to-peer

V modelu klient–server klient žádá a server poskytuje službu. Role nejsou vlastností konkrétního hardwaru: tentýž počítač může být v jedné komunikaci klientem a v jiné serverem.

U peer-to-peer mohou uzly [[ pouze přijímat data | (současně prostředky přijímat i poskytovat) | komunikovat výhradně přes webový server ]]. P2P tedy mění organizaci komunikace, ale stále používá síťové adresy a protokoly.

## URL jako adresa zdroje

URL může obsahovat schéma, hostitele, port, cestu, parametry dotazu a fragment. V adrese https://example.cz/clanky?id=7#obsah je https [[schéma]], example.cz hostitel a část za znakem # fragment uvnitř výsledného dokumentu.

URL není jen text k zobrazení. Jednotlivé části určují, jaký protokol použít, který server kontaktovat a o jaký zdroj požádat.
